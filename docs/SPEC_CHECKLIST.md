# 명세 체크리스트

공모 명세와 평가 체크리스트(「보통」)를 한 줄씩 옮기고, 담당 이슈와 검증 근거를 연결한다.
이슈를 머지할 때마다 상태와 근거를 갱신한다. 근거가 없는 ✅는 두지 않는다.
항목별 테스트 파일·테스트 이름과 테스트로 증명하지 못하는 것은 [TEST_SPEC.md](TEST_SPEC.md)에 있다(§2 추적표, §6 수동 확인).

상태: ⬜ 미착수 · 🔧 진행 중 · ✅ 완료(근거 있음) · ⚠️ 부분 완료(사유 기재)

현재 테스트 건수(2026-11-10): API 통합 409, 웹 단위 53, 브라우저 E2E 9개 파일.
